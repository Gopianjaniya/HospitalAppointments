#  Hospital Appointment System (MERN)

A full-stack web application for managing doctor appointments, allowing patients to book and manage appointments efficiently.

---

##  Live Demo
-  Frontend: https://hospital-frontend-henna.vercel.app/
-  Backend:  https://hospital-appointments-five.vercel.app

---

##  Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT

---

##  Features

### Patient Features
- User authentication (Signup / Login)
- Book doctor appointments
- View and cancel appointments

###  Doctor/Admin Features
- Manage appointments
- View patient details
- Handle scheduling efficiently

---

##  How It Works

1. User registers and logs in using JWT authentication  
2. Frontend sends requests to backend APIs  
3. Backend processes booking and stores data in MongoDB  
4. Users can book, view, or cancel appointments  
5. Admin/doctor can manage all appointments  

---

##  Architecture

- Frontend handles UI and API calls  
- Backend manages business logic and routes  
- MongoDB stores users and appointment data  
- JWT ensures secure access
